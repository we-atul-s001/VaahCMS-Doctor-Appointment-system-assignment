Project Overview

The VaahCMS Doctor Appointment System is a lightweight content module built on top of VaahCMS, designed to help clinics manage patient bookings, doctor schedules, and appointment notifications from a single dashboard.

This page exists to validate that the end-to-end auto-PR workflow — commit, branch push, automated review, and merge — functions correctly on GitHub. The README footer change that triggered this run was trivial on purpose.

To learn more about how this module fits into the broader ecosystem, see the features section below or jump to the resources list.

Core Features

  • Doctor profiles — Specialty, availability, and bio fields.
  • Patient booking — Frontend form with date and time-slot picker.
  • Email notifications — Confirmation and reminder messages.
  • Admin dashboard — Daily, weekly, and monthly appointment views.
  • REST API — Headless access for mobile clients.
  • Role-based access — Admin, doctor, and receptionist roles.
